Phase 2 ~15 min Advanced

Creative QA & ClickTag Setup

HTML5 Ad Tester

Google's Official Validator Launch Quick Tester
  • Extract/Upload ZIP dari creative team.
  • Verifikasi animasi load tanpa layar kosong.
  • Klik banner — apakah membuka tab baru?
  • Dimensi sesuai media plan?

CM360 Click Macro Reference

CM360 menyuntik click-tracking via macro. Pilih yang tepat sesuai konteks pemakaian.

%%CLICK_URL_UNESC%%

Un-escaped — dipakai saat URL langsung diteruskan ke window.open() / variabel clickTag. Default untuk HTML5. Masih valid per dokumentasi CM360 terbaru.

%%CLICK_URL_ESC%%

Escaped — dipakai saat URL di-append sebelum landing page (mis. redirect bertingkat / di-encode lagi).

Catatan: jika kreatif punya lebih dari satu area klik (multiple clickTags), setiap area butuh variabel clickTag terpisah (mis. clickTag2, clickTag3) yang masing-masing di-assign ke Landing Page berbeda saat Creative Assignment di CM360.

Manual ClickTag Insertion

Kalau kreatif HTML5 gagal click-test, sisipkan macro CM360 secara manual ke file .html banner. Ikuti 3 langkah.

1 Add variable in <head>

Definisikan destination URL pakai macro un-escaped CM360.

<script type="text/javascript">
  var clickTag = "%%CLICK_URL_UNESC%%";
</script>

2 Create an invisible click layer

Tambahkan overlay div (ad-button) yang menutupi seluruh banner.

<!-- Example: wrapping Adobe Animate Canvas -->
<div id="animation_container" style="width:320px;height:480px;position:relative;">
    <canvas id="canvas"></canvas>
    <!-- ADD THIS LAYER OVER YOUR CANVAS -->
    <div id="ad-button" style="width:100%;height:100%;position:absolute;top:0;left:0;z-index:999;cursor:pointer;"></div>
</div>

3 Add the event listener

Letakkan tepat sebelum </body> agar layer memicu clickTag.

<script>
document.getElementById('ad-button').addEventListener('click', function() {
    if (typeof clickTag !== 'undefined' && clickTag) {
        window.open(clickTag, '_blank');
    }
});
</script>
Phase 3 ~20 min Automated

Taxonomy on AppScript

Tutorial lengkap memakai otomasi Google Sheets AppScript untuk generate naming convention & format Import CM360 hanya dengan 1-Klik.

Wajib: simpan sebagai CSV sebelum import

Dokumentasi resmi CM360 mensyaratkan file bulk sheet di-save sebagai .csv sebelum diupload lewat tombol Import — file .xlsx hasil export AppScript sering ditolak atau kolomnya salah baca. Buka file Excel-nya, File › Save As › CSV (Comma delimited), baru upload versi CSV itu ke CM360.

AppScript: CPD (Full Serve)

Pakai menu 🤖 CM360 Tools di top bar Spreadsheet.

Open CPD Taxonomy Sheet
1

Run Taxonomy Sync

Pilih 🤖 CM360 Tools › 1. Generate & Sync Taxonomy (Active Sheet). Script membaca nama publisher, mengidentifikasi PO Number (akan prompt jika kosong), dan generate taxonomy standar.

2

Initial Setup di CM360

Buat base assets dulu di CM360:

  • Campaign: buat campaign baru. Advertiser = Djarum_ID. Jawab pertanyaan EU political ads dengan "No, this campaign doesn't have EU political ads". Set start & end date persis.
  • Landing Pages: Landing Page › Batch. Copy kolom "LP Name" & "LP URL" dari sheet, paste, save.
  • Creatives: New › Creative › Batch Upload. Upload semua ZIP HTML5 yang sudah lolos QA.
3

Isi Kolom Kuning

Kolom Creative ID & LP ID di-highlight kuning . Ambil ID dari CM360:

  • Creative ID: copy ID di samping asset yang diupload (mis. creative 320×480).
  • LP ID: buka Campaign Properties › section Landing Pages, copy teks berisi ID (mis. Detik_FC_Apps 42576935). Ambil angkanya, paste ke sheet.
4

Generate Export & Import

Setelah ID terisi, klik 🤖 CM360 Tools › 2. Generate Format CM360 Import. Download sebagai Excel, lalu save-as CSV (lihat catatan merah di atas). Di Campaign CM360 klik Import (kanan atas), upload file CSV, Save — semua ads, placements, & assignment terbentuk otomatis. Placeholder ID baris baru harus mengandung minimal satu huruf/simbol (mis. PL-01), tidak boleh angka murni.

5

Cek Sheet Status

Setelah upload, klik Sheet Status di campaign untuk memantau progress import — proses berjalan async dan bisa perlu beberapa menit untuk campaign besar. Jika ada baris error, CM360 menandai baris & alasan spesifiknya di kolom status.

AppScript: OTT (Tracker Only)

Pakai menu 🎬 OTT/Tracker Tools.

Open OTT Taxonomy Sheet
1

Run Taxonomy OTT

Pilih 🎬 OTT/Tracker Tools › 1. Generate & Sync Taxonomy OTT. Script mengekstrak platform (WeTV, Vidio) & konteks campaign (SeaGames, Mobile) untuk membangun Smart Contextual Landing Page Logic.

2

Setup Trackers di CM360

Buat Campaign & Batch Upload Landing pages seperti CPD. Tapi untuk Creatives, buat manual New › Creative › Tracking tiap placement (bukan upload HTML5), atau pakai fitur Batch Upload Third-Party Asset URLs jika volume tracker banyak.

3

Isi Kolom Kuning

Copy Tracking Creative ID & LP ID dari CM360, paste ke kolom kuning di sheet taxonomy.

4

Generate Export & Import

Jalankan 🎬 OTT/Tracker Tools › 2. Generate Format CM360 Import. Download, save-as CSV, lalu import via tombol Import di CM360. Berbeda dgn CPD, script otomatis set Ad & Creative Type = "Tracking" dan dimensi = "1×1".

Behind the scenes

Script menyimpan mapping di variabel SITE_MAP & SITE_MAP_OTT. Jika ada Publisher/Vendor baru & muncul alert "Mapping Failed", tambahkan publisher + CM360 Site ID-nya ke var SITE_MAP via menu Extensions › Apps Script.

Phase 4 ~15 min Manual UI

Manual Setup: CPD

Jika API/Import gagal atau ada brief ad-hoc mendadak, ikuti alur UI CM360 berikut.

1

Campaign Creation

Create Campaign › isi Campaign Name › Advertiser: Djarum_ID › set Schedule Start & End date › jawab deklarasi EU political ads.

2

Landing Pages

Klik tombol Landing Page. URL tunggal: isi Name & URL. Banyak: klik Batch (butuh 2 kolom Excel: Name & URL) lalu paste.

3

Upload Creatives

Klik New › Creative › Batch Upload. Upload ZIP HTML5 yang lolos QA. Catatan: fitur "Creative Projects"/Ads Creative Studio sudah di-sunset — gunakan alur Batch Upload standar ini.

4

Setup Placement

Klik New › Placement. Pilih Publisher (mis. Kompas). Isi Placement Name, set Dimensi sesuai brief, Save.

5

Ad & Assignments

1. Ad Creation: Ad › New › Standard. Nama sama dgn Placement. Set Active.

2. Creative Assignment: scroll ke "Edit Creative Assignments". Assign creative ukuran yang sesuai. Scroll kanan untuk attach Landing Page.

3. Placement Assignment: assign Ad ke Placement yang baru dibuat. Save.

6

Generate Tags

Klik tombol Tags (kanan atas), download Excel tags, email ke Planner.

Phase 5 ~12 min Manual UI

Manual Setup: OTT (Tracking)

Setup hanya mengandalkan 1×1 tracking pixel, bukan asset fisik.

What We DON'T Do

Karena tracking-only, kita tidak Batch Upload file HTML5/Video. Vendor yang host asset fisiknya.

What We DO

Kita generate impression & click tracking pixel di CM360 untuk diimplementasi publisher agar performa ter-map ke dashboard.

1

Campaign Creation

Create Campaign › OTT Campaign Name › Advertiser: Djarum_ID › set Schedule Start & End date › jawab deklarasi EU political ads.

2

Landing Pages

Set Landing Pages. Bisa pakai Batch entry jika punya banyak contextual landing page.

3

Create Tracking Creative

JANGAN Batch Upload. Klik New › Creative › Tracking. Beri nama identik dgn placement.

4

Setup 1×1 Placement

Klik New › Placement. Pilih Publisher (mis. Vidio.com). Isi Placement Name. Crucial: set dimensi strictly ke 1×1.

5

Ad & Assignments

1. Ad Creation: Ad › New › Standard. Set Active.

2. Creative Assignment: di "Edit Creative Assignments" pilih Tracking Creative tadi. Map Landing Page untuk placement ini.

3. Placement Assignment: assign Standard Ad ke 1×1 Placement, Save.

6

Generate Tags

Klik Tags (kanan atas), download Excel tags. Berikan tracking pixel ini ke OTT vendor. Jika publisher butuh pixel tambahan (viewability/verification pihak ketiga), gunakan kolom Third-Party Vendor Tracking Tag yang sekarang mendukung multi-event (impression, start, firstQuartile, midpoint, complete).

Phase 6 ~8 min QA

Publisher Preview Verification

Cara verifikasi tracker firing dengan benar saat publisher mengirim preview link.

Example Publisher Link

https://pubads.g.doubleclick.net/gampad/preview_cookie?gct=E0btTJ5o5l…&redirect=https://www.vidio.com/watch/…

Verification Workflow

1

Open & Inspect

Buka link di Chrome. Klik kanan › Inspect (atau F12). Buka tab Network.

2

Toggle Device View

Klik Device Toolbar (Ctrl+Shift+M). Mobile placement: pilih iPhone/Android. Desktop: matikan.

3

Filter Network Traffic

Di filter box Network, ketik ad.double untuk isolasi request CM360, atau paste Placement ID. Refresh untuk mulai capture.

4

Verify Status

Pastikan ad visible & clickable. Cek Network: request fired dengan Status 200 (OK).

Catatan cookie & pengukuran (2026)

Google Marketing Platform kini menambah dukungan CHIPS (partitioned cookies) dan first-party local storage untuk Floodlight, jadi jangan panik kalau angka klik di 3rd-party publisher sedikit berbeda dari CM360 — ini normal karena metode atribusinya makin privacy-safe. Selisih besar (bukan cuma beda kecil) baru dianggap "not firing".

Not Firing?

Jika ID tidak muncul atau ad blank setelah refresh, tracker tidak firing. Segera infokan planner/publisher untuk memperbaiki implementasi.

CM360 Platform Updates (2025–2026)

Ringkasan perubahan resmi Google Marketing Platform yang paling relevan untuk workflow Djarum. Cek fase ini tiap kuartal — Google mengumumkan update di "Coming soon" release notes CM360.

Ads Creative Studio & "Creative Projects" — sunset

Ads Creative Studio sudah di-retire, dan section Creative Projects dihapus dari UI CM360. Creative yang dulu ada di creative project tetap bisa diassign/serve seperti biasa dan dapat diakses dari Creative Library milik Advertiser masing-masing; ads yang dibuat dari creative project jadi Standard Ad biasa.

Field "Natural Search" dihapus

Karena traffic hampir seluruhnya sudah HTTPS, dimensi/metrik Natural Search resmi dihapus dari UI & API CM360 (efektif awal 2026). Update template report yang masih mereferensikan field ini.

Paid Social (dari SA360) tidak lagi muncul di CM360

Metrik & dimensi Paid Social yang sebelumnya bersumber dari Search Ads 360 (mis. data Meta) sudah di-deprecate dari report template CM360. Untuk insight paid social lengkap, cek langsung di interface Search Ads 360.

Self-serve Google Ads pixel linking

CM360 sekarang mendukung link langsung ke akun Google Ads untuk apply click/impression pixel secara instan (self-service), tanpa perlu request manual — berguna untuk campaign YouTube & Display yang overlap dengan Google Ads.

Multi-event Third-Party Vendor Tracking Tag

Kolom "Third-party vendor tracking tag" di tag sheet sekarang mendukung banyak tag sekaligus (impression, start, firstQuartile, midpoint, complete, error) — relevan untuk placement video/OTT yang butuh verifikasi pihak ketiga lengkap.

CHIPS & first-party storage untuk Floodlight

Floodlight kini memakai partitioned cookies (CHIPS) dan local storage first-party untuk memulihkan pengukuran conversion di tengah pembatasan cookie browser modern. Tidak perlu aksi manual, tapi baik untuk dipahami saat menjelaskan diskrepansi angka ke klien.

Rebranding partner exchange: Unruly → Nexxen

Nama exchange "Unruly" berubah jadi "Nexxen" di filter/inventory source CM360 — perubahan brand saja, tidak ada perubahan serving.

Sumber resmi

Selalu cek halaman "Announcements" Campaign Manager 360 Help untuk update ter-terbaru sebelum onboarding campaign besar — dokumen ini dirangkum manual dan bisa tertinggal beberapa minggu dari rilis resmi Google.
